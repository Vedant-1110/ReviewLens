# ⭐ ReviewLens

ReviewLens is a Python-based restaurant review scraping and analytics project that collects reviews from Google Maps and turns them into useful insights through an interactive dashboard.

The project combines **Selenium for web scraping, Pandas for data analysis, Plotly for visualization, and Streamlit for the dashboard.**

## 📌 Project Overview

Restaurant reviews contain useful information about customer experiences, but manually analyzing hundreds of reviews can be difficult.

ReviewLens automates this process:

Google Maps
     ↓
Selenium Web Scraper
     ↓
Restaurant Reviews
     ↓
CSV Dataset
     ↓
Pandas Data Analysis
     ↓
Review Insights
     ↓
Interactive Streamlit Dashboard

🚀 Features
🔎 Search restaurants through Google Maps
🤖 Automated review collection using Selenium
⭐ Rating analysis
😊 Rating-based sentiment grouping
📝 Review text analysis
🔤 Most common word analysis
📊 Interactive charts and visualizations
🔍 Filter reviews by restaurant, rating, and sentiment
📋 View collected reviews in a table
📥 Download filtered review data as CSV
🔄 Automated scraping → analysis → dashboard workflow
